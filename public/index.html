import express from 'express';
import { tollbooth } from '@agenttoll/sdk';

const app = express();

// Protect API routes with a toll for AI agents
app.use('/api/v1', tollbooth({
  apiKey: process.env.AGENTTOLL_KEY,
  price: 0.001,          // $0.001 USDC per request
  freeForHumans: true,   // Browser traffic passes free
}));

// Your existing routes work unchanged
app.get('/api/v1/weather', async (req, res) => {
  const data = await fetchWeatherData(req.query.city);
  res.json(data);
});

app.listen(3000);

How it works

Four steps from request to payment. No changes to your business logic.

1

Agent sends request

AI agent calls your API. AgentToll middleware intercepts the request.

GET /api/v1/weather?city=tokyo
2

402 Payment Required

Without a valid token, agent receives payment instructions.

{ "amount": 0.001, "currency": "USDC" }
3

Agent pays on Solana or Base

Agent sends USDC to the wallet. Confirms in seconds.

tx: 5K7x...confirmed
4

Access granted

Agent receives JWT token and retries. Your API returns data.

Authorization: Bearer eyJhbG...

Get started in 5 minutes

Three steps to start accepting payments from AI agents.

1

Get your API key

Sign up and create your first project to get credentials.

curl -X POST https://toll.agenttoll.io/api/publisher/register \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com"}'
2

Install the SDK

Add AgentToll to your project with npm or yarn.

npm install @agenttoll/sdk
3

Add the middleware

Wrap your routes with the tollbooth middleware.

import { tollbooth } from '@agenttoll/sdk';

app.use('/api', tollbooth({
  apiKey: process.env.AGENTTOLL_KEY,
  price: 0.001
}));
