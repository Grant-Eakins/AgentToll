How it works

Four steps from request to payment using the x402 protocol. No changes to your business logic.

1

Agent sends request

AI agent calls your API. AgentToll middleware intercepts and detects the agent.

GET /api/v1/weather?city=tokyo
2

x402: Payment Required

Middleware returns HTTP 402 with x402-compliant payment instructions agents can parse.

HTTP 402 + X-402-Amount: 0.001
3

Agent pays on Solana or Base

Agent sends USDC to the wallet and submits tx proof. Confirms in seconds.

tx: 5K7x...confirmed
4

Access granted

Agent receives JWT token and retries. Your API returns data normally.

Authorization: Bearer eyJhbG...
