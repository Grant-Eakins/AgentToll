Overview

AgentToll lets you monetize your API for AI agents with micropayments. When an agent requests your data, they pay a small USDC toll and get instant access.

💡 Key Benefits

  • Simple integration with Express, Next.js, Cloudflare Workers
  • Instant USDC payments on Solana or Base
  • Standard HTTP 402 protocol for cross-agent compatibility
  • No subscriptions to manage - pure pay-per-use

Quick Start

1. Register as a Publisher

curl -X POST https://toll.agenttoll.io/api/publisher/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Your Company",
    "email": "you@example.com",
    "wallets": { "solana": "YOUR_WALLET_ADDRESS" }
  }'

You'll receive an API key like pk_live_abc123...

2. Install the SDK

npm install @agenttoll/sdk

3. Add to Your Server

const express = require('express');
const tollbooth = require('@agenttoll/sdk');

const app = express();

// Toll all routes under /api/premium
app.use('/api/premium', tollbooth('pk_live_xxx', {
  amount: 0.01,
  freeForHumans: true
}));

app.get('/api/premium/data', (req, res) => {
  res.json({ premium: 'data' });
});

That's it! Your API now accepts USDC payments from AI agents.

How Tolling Works

The Payment Flow:

  1. Agent requests your API — GET /api/premium/weather
  2. Tollbooth returns 402 — Detects AI agent by User-Agent
  3. Agent reads payment info — Amount, wallet, supported networks
  4. Agent sends USDC — Direct transfer on Solana or Base
  5. Agent calls /api/pay — With transaction proof
  6. Receives access token — JWT for authorization
  7. Retries original request — With Authorization: Bearer token
  8. Data delivered! ✅

Access Modes

Choose how tokens grant access to your API. This controls what agents can do after paying.

MODE per-request

Token valid for exactly 1 API request

Best for: High-value queries, expensive computations, preventing bulk scraping

// Publisher config
{
  "access_mode": "per-request",
  "default_amount": 0.001  // $0.001 per query
}

// Agent pays → gets token → uses once → must pay again
MODE session DEFAULT

Token valid for specific resource within time window

Best for: General API access, repeated queries to same endpoint

// Publisher config
{
  "access_mode": "session",
  "access_duration": "1h",
  "default_amount": 0.01  // $0.01 for 1 hour
}

// Agent can access same endpoint unlimited times for 1 hour
MODE pass

Token valid for ALL publisher endpoints within time window

Best for: Content sites, documentation, full API exploration

// Publisher config
{
  "access_mode": "pass",
  "access_duration": "24h",
  "default_amount": 0.50  // $0.50 for 24h full access
}

// Agent gets full site access to any endpoint

⚠️ Choosing the Right Mode

  • per-request — Maximum protection, higher friction
  • session — Balanced, good for most APIs
  • pass — Easiest for agents, allows more data access

Supported Networks

Payments are accepted in USDC on:

Network Currency Contract/Mint Speed
Solana USDC (SPL) EPjFWdd5...TDt1v ~400ms
Base USDC (ERC20) 0x833589...02913 ~2s

💡 Single Wallet OK

You only need ONE network. If you only have a Solana wallet, that's fine!

HTTP 402 Response Format

When an agent needs to pay, they receive:

{
  "status": 402,
  "message": "Payment Required",
  "agent_instructions": "Pay 0.005 USDC to access...",
  "payment": {
    "amount": 0.005,
    "currency": "USDC",
    "network": "solana",
    "receiver_wallet": "ABC123...",
    "pay_url": "https://toll.agenttoll.io/pay?..."
  },
  "access": {
    "mode": "session",
    "duration": "1h"
  },
  "retry": {
    "url": "https://your-api.com/data",
    "headers": { "Authorization": "Bearer <token>" }
  }
}

Headers included:

X-402-Version: 1
X-402-Amount: 0.005
X-402-Currency: USDC
X-402-Pay-URL: https://toll.agenttoll.io/pay?...

Payment Endpoints

POST /api/pay

Submit payment proof and receive access token.

Request Body

Field Type Description
publisherrequired string Publisher API key
amountrequired number Amount paid in USDC
tx_signature string Solana transaction signature
tx_hash string Base transaction hash
networkoptional string solana (default) or base

Response

{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "expires_in": 3600,
  "access": {
    "mode": "session",
    "duration": "1h",
    "scope": "single resource"
  }
}
GET /api/pay/quote

Get payment quote before paying — wallet address, amount, fees, access mode.

Query Parameters

publisherrequired Publisher API key
networkoptional solana (default) or base

Verification Endpoints

POST /api/verify

Verify a payment token (middleware uses this internally).

Request Body

tokenrequired JWT access token
publisherrequired Publisher API key
resourceoptional Resource path for scope check

Response

{
  "valid": true,
  "access": {
    "mode": "session",
    "scope": "/api/data",
    "expires_at": "2024-01-15T12:00:00Z",
    "uses_remaining": null
  }
}

Publisher Registration

POST /api/publisher/register

Register as a publisher to receive payments.

Request Body

namerequired Your company/project name
emailrequired Contact email
walletsrequired Object with network addresses

Example

{
  "name": "Weather API Co",
  "email": "api@weather.com",
  "wallets": {
    "solana": "ABC123...",
    "base": "0x1234..."
  }
}

Response

{
  "success": true,
  "publisher_id": "uuid-xxx",
  "api_key": "pk_live_abc123...",
  "secret_key": "sk_live_xyz789...",
  "integration": {
    "one_liner": "app.use(require('@agenttoll/sdk')('pk_live_abc123...'))"
  }
}

⚠️ Save Your Keys

The secret_key is only shown once. Store it securely!

Registration Methods

Option 1: Web UI (Easiest)

Click "Get API Key" on the homepage to use the registration form.

Option 2: cURL

curl -X POST https://toll.agenttoll.io/api/publisher/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My API",
    "email": "me@example.com",
    "wallet_address": "YourSolanaWallet"
  }'

Option 3: Programmatic (JavaScript)

const response = await fetch('https://toll.agenttoll.io/api/publisher/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'My API',
    email: 'me@example.com',
    wallets: {
      solana: 'SolanaWalletAddress',
      base: '0xBaseWalletAddress'  // optional
    }
  })
});

const { api_key, secret_key } = await response.json();
// Store these in your .env file:
// AGENTTOLL_KEY=pk_live_xxx
// AGENTTOLL_SECRET=sk_live_xxx

Environment Variables

After registration, add your key to your environment:

# .env
AGENTTOLL_KEY=pk_live_abc123...

Middleware Setup

Express.js

import tollbooth from '@agenttoll/sdk';
// Or: const tollbooth = require('@agenttoll/sdk').default;

// Protect specific routes
app.use('/api/premium', tollbooth(process.env.AGENTTOLL_KEY, {
  amount: 0.01
}));

// Free for humans, toll for agents
app.use('/api/data', tollbooth(process.env.AGENTTOLL_KEY, {
  amount: 0.005,
  freeForHumans: true
}));

// Or use the convenience method
app.use('/api/v1', tollbooth.agentsOnly(process.env.AGENTTOLL_KEY));

Next.js API Routes

import { tollMiddleware } from '@agenttoll/sdk/edge';

export async function middleware(request) {
  return tollMiddleware(process.env.AGENTTOLL_KEY, {
    amount: 0.01
  })(request, () => NextResponse.next());
}

Cloudflare Workers

import { tollgate } from '@agenttoll/sdk/edge';

// One-liner: wrap your entire worker
export default tollgate(PUBLISHER_KEY, { amount: 0.01 });

// Or with custom handler
export default {
  async fetch(request, env) {
    const gate = tollgate(env.AGENTTOLL_KEY, { amount: 0.01 });
    return gate.fetch(request, env);
  }
};

SDK Options Reference

Full list of options for the tollbooth middleware:

tollbooth(apiKey, options)
Option Type Default Description
amount number 0.005 USDC amount to charge per request/session
freeForHumans boolean false Let browser requests through without payment
paths string[] ['*'] Glob patterns for routes to toll (e.g., ['/api/*'])
walletAddress string null Override default wallet for this middleware
bypassHeader string null Header name that bypasses toll (for internal services)

Convenience Methods

// Toll only AI agents, humans pass free
tollbooth.agentsOnly(apiKey, options)

// Protect a single route
tollbooth.protect(apiKey, options)

// Check if request already paid
tollbooth.hasPaid(req)  // returns boolean

// Check if request is from an AI agent
tollbooth.isAgent(req)  // returns boolean
